# 诡道仙途

> 中式克苏鲁风格文字冒险游戏 - 修仙世界观

## 游戏简介

世人皆求仙道，唯我窥见深渊。

当你踏入青云宗的那一刻，命运的齿轮便开始转动。这是一个融合中国修仙元素与克苏鲁神话的诡异世界——你会发现所谓的"仙门"，不过是被上古邪神"太岁"侵蚀的封印之地。

## 游戏特色

- 🔮 **独特世界观** - 中式修仙 × 克苏鲁恐怖，仙道表面下的深渊
- 🧠 **神智与污染系统** - 探索越深，神智越低，污染越重
- 📖 **分支剧情** - 你的每一个选择都会影响故事走向
- 💀 **多结局** - 堕落成神、以身封印、或是带着噩梦逃离...
- 📱 **移动端适配** - 完美支持手机竖屏游玩

## 游戏系统

| 系统 | 说明 |
|------|------|
| 神智 (0-100) | 代表理智，越低越容易看到不该看的东西 |
| 污染 (0-100) | 被太岁侵蚀程度，过高会失去人性 |
| 修为 | 修仙境界，影响可探索深度 |
| 物品 | 黄符、镇魂香等可抵抗负面影响 |

## 如何游玩

直接打开 `index.html` 即可开始游戏，无需服务器！

### 本地游玩
```bash
# 克隆仓库
git clone https://github.com/Yue8080/gui-dao-xian-xia.git
# 用浏览器打开 index.html
```

### 在线游玩
访问 GitHub Pages: https://yue8080.github.io/gui-dao-xian-xia

## 技术栈

- 纯 HTML/CSS/JavaScript，无任何依赖
- Google Fonts (马善政书法字体、有道小薇)
- 响应式设计，适配手机/平板/桌面
